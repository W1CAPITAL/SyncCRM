# **App Name**: SyncCRM

## Core Features:

- Intelligent Sheet Mapping: An AI-powered tool that reasons about your spreadsheet headers and automatically maps them to CRM fields, ensuring data integrity without manual configuration.
- OAuth-Driven Connectivity: Secure Google account integration allowing the app to fetch and interact with specific spreadsheets only after user authorization.
- Cross-Tab Explorer: Navigate and access data across multiple sheets and tabs within a single workbook via a clean dashboard interface.
- Conflict-Free Batch Writing: Utilizes a sync queue to push updates to Google Sheets in batches, preventing data loss or accidental formula overwrites.
- Data Consistency Monitor: Uses AI to scan for structural changes in the underlying spreadsheet and alert the user before operations proceed, avoiding breakages.
- Change Audit History: Persistent record of all modifications made through the CRM, stored for transparency and recovery purposes.
- Firebase State Sync: Real-time mirroring of sheet data to a local state to ensure a responsive, zero-latency user experience.

## Style Guidelines:

- Primary color: Deep Trust Blue (#174FCE), conveying reliability and professional clarity.
- Background color: Atmospheric White (#F7F9FB), providing a crisp and sterile workspace environment.
- Accent color: Vibrant Cyan (#10D6FF), used sparingly for interactive highlights and status indicators.
- Primary font: 'Inter', a grotesque sans-serif that ensures high legibility for data-heavy CRM records.
- Information-dense layout with sidebar navigation, maximizing screen real estate for viewing spreadsheet data.
- Systemic and outlined icon style to keep the focus on user data rather than decorative elements.
- Micro-interactions on row hover and subtle sliding transitions when switching between spreadsheet tabs.
